
## Sales analysis and interactive dashboard created using Microsoft Excel.

This project focuses on analyzing sales transaction data using Microsoft Excel. 
The analysis explores revenue, product performance, regional sales, customer types, 
sales channels, and sales trends.

PivotTables and Excel charts were used to summarize the raw data and create an 
interactive dashboard that makes the sales performance easier to understand.

## Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Excel Charts
- Data Cleaning & Analysis

## Project Objectives

- Analyze overall sales and revenue performance
- Compare sales across different regions
- Identify top-performing products and categories
- Analyze customer types and sales channels
- Understand sales trends over time
- Present the findings through an interactive dashboard

## Project Files

- `SalesData.csv` — Raw sales transaction data
- `Dashboard.png` — Final Excel dashboard
- `Pivot_Table.png` — PivotTable analysis
